Important: To use this mod, you need to change the following values in the file "config.ini"
(default location "Documents/My Games/Sid Meier's Civilization 5/"):

------------------------

[MiniMap]

; Mini-map width.
Width = 800

; Mini-map height.
Height = 475

------------------------


To revert to the original size of the minimap, use the following values:

------------------------

[MiniMap]

; Mini-map width.
Width = 320

; Mini-map height.
Height = 190

------------------------
